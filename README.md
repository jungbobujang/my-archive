# 나의 아카이브

아이디어, 유튜브 대본, 링크, 이미지, 할 일을 카테고리와 태그로 정리하는 개인 아카이브입니다.
자료가 수천 개 쌓여도 필요한 것만 페이지 단위로 불러오기 때문에 첫 화면 속도는 그대로입니다.

폰 홈 화면에 설치하면 주소창 없이 앱처럼 뜨고, 네트워크가 끊겨도 화면은 열립니다.

기술 스택: Vite + React 18 + Supabase (DB / Storage / Auth)

공통 개발 표준: [github.com/jungbobujang/dev-standards](https://github.com/jungbobujang/dev-standards)

---

## 기능

### 오늘 탭

- **오늘의 할 것** — 기한이 없거나 오늘까지인 할 일. 지난 기한은 🔴 로 표시
- **시간대(슬롯)별 묶음** — 아침·저녁 같은 시간대를 직접 만들어 할 일을 나눠 담고, 순서도 바꿀 수 있음
- **예정** — 내일 이후 기한이 있는 할 일 5개
- **미분류** — 어느 카테고리에도 안 들어간 항목 (전체 개수 + 최근 10개)
- **최근 저장** — 마지막에 넣은 5개

### 아카이브 탭

- **통합 검색** — 제목 + 내용, 300ms 디바운스, 서버 측 검색
- **계층 카테고리** — 상위/하위 구조. 상위 카드의 개수는 자손까지 합산
- **다중 소속** — 한 항목이 여러 카테고리에 동시에 속할 수 있음
- **태그 필터** — 항목당 최대 10개, 칩 클릭으로 필터
- **중요(★) / 할 것(⚡) 필터**
- **세 가지 보기** — 갤러리 ▦ / 리스트 ☰ / 마인드맵 🗺️ (선택은 기억됨)
- **마인드맵** — 카테고리 계층을 방사형으로. 노드의 + 버튼으로 하위 카테고리를 그 자리에서 추가
- **페이지네이션** — 24개씩 로드 후 "더 보기"

### 저장

- **빠른 저장** — 한 줄 입력 후 엔터. `!` 로 시작하면 할 일로 저장
- **새 항목** — 제목·링크(여러 개)·내용·태그·이미지(여러 장)·**파일(최대 5개)**·실행 상태·기한·시간대.
  **저장 창은 이것 하나다** (예전의 '여러 링크 저장' 창은 여기로 흡수했다)
- **제목은 선택** — 비우면 알아서 짓는다.
  링크가 있으면 첫 링크 제목(noembed) → 내용이 있으면 앞 20자 → 이미지뿐이면 `이미지 YYYY-MM-DD`
  (첨부 파일 이름은 쓰지 않습니다)
- **여러 링크 한 번에** — 링크칸에 여러 개를 붙여넣으면 `N개 링크 감지됨` 이 뜨고 저장 방식을 고른다.
  **한 항목에 모두 담기**(기본) / **링크마다 개별 항목**.
  개별 모드는 링크마다 제목을 noembed 로 받아 한 건씩 저장하고 진행률을 `n/N` 로 보여 준다.
  카테고리·태그·실행 상태는 전부에 공통 적용되고, **이미지와 내용은 첫 항목에만** 담긴다
- **유튜브 썸네일 자동** — 유튜브 링크면 썸네일을 알아서 붙임
- **내용에서 링크 자동 추출** — 본문에 URL 을 쓰면 링크 칸에 자동으로 모임
  (입력이 멈춘 뒤 0.5초에 한 번. 그 전에 저장을 눌러도 본문의 링크는 함께 담깁니다.
  ✕ 로 뺀 링크는 본문에 남아 있어도 다시 올라오지 않습니다)
- **저장 실패는 원인을 말합니다** — 로그인 만료(RLS)·보이지 않는 문자(22P05)·빈 제목·연결 끊김을
  각각 다른 문구로 알립니다. 링크마다 개별 항목으로 나눠 저장할 때는 실패한 링크 주소와 이유까지 적습니다
- **보이지 않는 문자 정리** — 저장 직전에 제목·본문·태그에서 NUL·짝 없는 서로게이트·제어문자를
  털어 내고 `보이지 않는 문자 N개를 정리했습니다` 로 알립니다 (탭·줄바꿈·이모지는 그대로)

#### 이미지 (한 항목에 최대 10장)

- **붙여넣기** — 항목 모달과 빠른 저장 줄에서 <kbd>Ctrl</kbd>+<kbd>V</kbd>.
  스크린샷을 찍고 바로 붙여넣으면 끝입니다. **끌어놓기**도 같습니다.
- **빠른 저장에 붙여넣으면** 그 자리에서 한 항목이 됩니다.
  입력칸에 쓴 글이 있으면 그게 제목이 되고(`!` 로 시작하면 할 것),
  비어 있으면 `이미지 YYYY-MM-DD` 로 만듭니다.
- **모달** — 썸네일이 가로로 늘어서고, 각각 ✕ 로 빼거나 눌러서 크게 볼 수 있습니다.
  첫 장에 `대표` 표시가 붙습니다.
- **카드** — 첫 장만 싣고 나머지는 `외 N장` 뱃지로 알립니다.
- **자동 축소** — 긴 변이 1600px 를 넘으면 비율을 지켜 줄여서 올립니다(webp, 안 되면 jpeg).
  줄인 게 원본보다 크면 원본을 씁니다. GIF·SVG 는 건드리지 않습니다(움직임이 죽습니다).

> **저장 구조 — `items.image_url` 한 열에 줄바꿈으로 담습니다. 표를 나누지 않았습니다.**
> 같은 표의 `link_url` 이 이미 같은 방식이고, 무엇보다 **옮길 데이터가 없습니다**
> (기존 한 줄짜리 값이 그대로 1장짜리 목록입니다). 표를 나누면 24개씩 받는 목록 조회에
> 페이지마다 조회가 하나 더 붙고, 그 매핑을 오늘·휴지통·마인드맵에도 각각 만들어야 하며,
> 백업 내보내기·가져오기 양쪽도 고쳐야 합니다(이 저장소는 예전에 `time_slots` 를
> 백업에서 빠뜨린 적이 있습니다). **그래서 이 기능에는 실행할 SQL 이 없습니다.**
> 한 장마다 캡션 같은 부가 정보가 필요해지면 그때 `item_images` 로 정규화합니다.

#### 파일 첨부 (한 항목에 최대 5개)

이미지 영역 **바로 아래** 에 있습니다. 이미지와 버킷도, 상한도 따로입니다.

- **[📎 파일 첨부]** 버튼이나 **끌어놓기**. 어느 칸에 떨어뜨려도 **이미지 확장자는 이미지로,
  나머지는 파일로** 알아서 갑니다.
- **받을 수 있는 것** — `hwp` `hwpx` `pdf` `docx` `xlsx` `pptx` `txt` `zip`. 그 밖은 거부합니다.
- **개당 10MB** — 올리기 전에 브라우저에서 먼저 재고, 넘으면
  `10MB 이하만 첨부할 수 있습니다 (현재 12.3MB)` 라고 알립니다.
- **목록** — 아이콘 + 원본 이름 + 용량. 누르면 내려받고, ✕ 로 뺍니다.
  긴 이름은 이름 쪽만 줄어들어 용량·✕ 를 밀어내지 않습니다.
- **카드** — 첨부가 있으면 `📎N` 뱃지가 붙습니다.
- **저장소 사용량** — 설정 화면에 `파일 ○○MB / 1GB` 게이지. 80% 를 넘으면 주황이 됩니다.

> **버킷은 `archive-files` 이고 비공개입니다.** 이미지 버킷은 공개지만, 파일 쪽은 문서·표·
> 압축본이 들어오는 자리라 주소만 알면 누구나 받을 수 있는 상태로 두지 않았습니다.
> 받을 때마다 60초짜리 서명 주소를 만들어 원본 이름으로 내려받습니다.
>
> **저장 키는 `{항목id}/{타임스탬프}_{원본명}`** 입니다. 원본 이름을 그대로 두면 스토리지를
> 직접 열어 봤을 때 무엇인지 알아볼 수 있습니다. 서버가 비ASCII 키를 거부하는 배포본이 있어,
> 그때만 퍼센트 인코딩한 키로 물러섭니다 — 화면에 보이는 이름은 어느 쪽이든 원본입니다.
> (새 항목은 아직 id 가 없어 `new-<uuid>` 임시 폴더에 올라갑니다. 지우기는 폴더가 아니라
> 경로 목록으로 하므로 나중에 항목 id 와 달라도 상관없습니다.)
>
> **메타는 `items.files` 한 열(jsonb)** 에 `[{ path, name, size }]` 로 담습니다.
> 이미지처럼 표를 나누지 않은 이유는 같지만, 파일은 이름과 용량을 함께 보여 줘야 해서
> 줄바꿈 문자열로는 담을 수 없어 jsonb 로 갔습니다. 열 하나가 늘 뿐이라 목록 조회도
> 백업 내보내기·가져오기도 지금 코드 그대로 돕니다.
> **이 기능에는 실행할 SQL 이 있습니다** — `supabase/setup.sql` 을 다시 한 번 Run 하세요
> (`TODO-SQL.md` 참고). 실행 전에는 첨부만 항목에 붙지 않고, 나머지 저장은 그대로 됩니다.

#### 고아 파일

올렸는데 어디에도 붙지 않은 파일이 스토리지에 남지 않도록 네 자리를 막아 두었습니다.

- 모달을 **저장하지 않고 닫으면** 이번에 올린 이미지·파일을 지웁니다.
  (그래서 임시 보존된 초안에서도 함께 빠집니다. 글·링크·카테고리는 그대로 남습니다.)
  <kbd>Esc</kbd> 로 닫을 때 뜨는 확인창이 **"첨부한 이미지/파일도 함께 삭제됩니다"** 라고 알립니다.
- **✕ 로 뺀 것** — 이번에 올린 것이면 그 자리에서, 원래 붙어 있던 것이면 **저장이 끝난 뒤에** 지웁니다.
  취소하면 원래 있던 것은 그대로입니다.
- **영구 삭제·휴지통 비우기** — 항목에 붙어 있던 **파일과 이미지** 를 스토리지에서 함께 지웁니다.
  (휴지통으로 보내는 것은 복원할 수 있어야 하므로 지우지 않습니다.
  유튜브 썸네일처럼 우리 버킷 밖의 주소는 지우려 들지 않습니다.)
- **빠른 저장이 실패하면** 방금 올린 이미지를 되돌립니다.

> **초안(임시 보존)에 파일은 넣지 않습니다.** 닫을 때 지우기 때문입니다 —
> 초안에 남겨 두면 다시 열었을 때 이미 없는 파일을 가리키게 됩니다.

> **초안은 입력이 멈춘 뒤 0.5초에 한 번만 씁니다.** 글자마다 쓰면 대본처럼 긴 글에서
> 타이핑이 밀립니다. **본문이 1MB 를 넘으면 초안을 건너뛰고** 모달 안에 그 사실을 한 줄로
> 알립니다(sessionStorage 는 탭당 몇 MB 뿐입니다). 창을 닫을 때는 크기와 상관없이
> 마지막으로 한 번 더 남겨 봅니다 — 쓴 글을 그냥 버리지 않기 위해서입니다.

### 관리

- **휴지통** — 삭제는 soft delete. 복원 / 영구 삭제 / 전부 비우기
- **백업 내보내기·가져오기** — 항목·카테고리·시간대·소속 전체를 JSON 으로.
  가져오기는 덮어쓰기(upsert)라 기존 데이터가 지워지지 않음.
  시간대가 없는 옛 백업 파일도 그대로 복원됩니다
- **카테고리 관리** — 이름·아이콘·색(8색)·상위 카테고리 변경, 순환 참조 방지
- **시간대 관리** — 이름·아이콘·순서

### 자리비움 잠금

자리를 뜬 사이 화면을 가리는 기능입니다. **기본은 꺼져 있고, PIN 을 걸어야 켤 수 있습니다.**

- **PIN 4자리** — 설정 → 자리비움 잠금에서 등록·변경. 풀 때는 네 자리를 한 번만 넣습니다
  (다 넣으면 확인 버튼 없이 바로 열립니다)
- **기기마다 따로 켭니다** — 설정은 이 기기(localStorage)에만 있습니다.
  교무실 컴퓨터에서는 켜고 집 노트북에서는 꺼 두는 식으로 씁니다
- **유예시간 5 / 15 / 30분** (기본 15분) — 이만큼 입력·터치·스크롤이 없으면 잠깁니다
- **한 번 풀면 2시간은 다시 안 잠깁니다** — 방금 풀었는데 또 잠기는 일을 막습니다
- **수동 잠금 🔒** — 헤더의 자물쇠 버튼, 또는 `Ctrl`(`⌘`)+`Shift`+`L`.
  자동 잠금 스위치를 꺼 둔 기기에서도 눌러서 즉시 잠글 수 있습니다
- **PIN 10회 실패** — 잠금을 그만 묻고 로그아웃합니다(다시 로그인해야 합니다)
- **잠긴 동안에는 본문을 아예 그리지 않습니다** — 가림막으로 덮는 것이 아니라
  화면에서 내립니다. 그래서 탭 전환·내보내기·모달로 우회할 자리가 없습니다.
  쓰던 글은 초안으로 남아 풀면 되돌아옵니다

PIN 은 평문으로 저장하지 않고 PBKDF2(SHA-256, 20만 회, 임의 소금)로 바꿔 둡니다.
다만 네 자리는 경우의 수가 1만 개뿐이라, **기기를 통째로 가져간 사람을 오래 막지는 못합니다.**
이 기능이 막는 것은 잠깐 자리를 비운 사이 지나가던 사람이 화면을 보는 일입니다.
진짜 접근 통제는 Supabase 로그인이 합니다.

### 화면

- **설정** — 상단 ⋯ → 설정. 화면 테마(시스템 / 라이트 / 다크), 자리비움 잠금, 플랜 표시, 로그인 계정
- **다크 모드** — 시스템 설정 자동 + 수동 전환. 카테고리 8색 모두 다크 버전이 있고 대비는 라이트와 동일 수준
- **요금제 안내(`/pricing`)** — 무료 / 프로 2단 비교. **정적 초안이며 결제 연동은 없습니다.**
  표의 한도는 자리표시 숫자로, 앱 어디에서도 강제되지 않습니다
- **PWA** — 홈 화면 설치, 오프라인에서도 앱 셸이 열림
- **모바일 최적화** — 380px 기준으로 레이아웃·터치 영역 정리
- **실패 안내** — 저장·조회 실패는 토스트로, 모달 안 오류는 인라인으로

## 1. Supabase 설정 (약 5분)

1. [supabase.com](https://supabase.com) 에서 새 프로젝트를 만듭니다.
2. 왼쪽 메뉴 **SQL Editor** → `supabase/setup.sql` 내용 전체를 붙여넣고 **Run**.
   - 테이블 4개(categories / time_slots / items / item_categories), RLS 정책,
     인덱스, 이미지 버킷(archive-images), 파일 버킷(archive-files, 비공개)이
     한 번에 만들어집니다.
   - 이 파일 하나면 됩니다. 여러 번 다시 실행해도 안전합니다.
3. **Authentication → Users → Add user** 에서 본인 계정(이메일/비밀번호)을 직접 만듭니다.
   - 계정을 만드는 순간 기본 카테고리 4종(아이디어 / 유튜브 대본 / 이미지 / 기타 메모)과
     시간대 5종(아침 / 오전 / 오후 / 저녁 / 밤)이 자동으로 생깁니다. 마음대로 고치거나 지우면 됩니다.
   - 다른 사람의 가입을 막으려면 **Authentication → Sign In / Up** 에서 Sign-ups 를 꺼 두세요.
4. **Project Settings → API** 에서 두 값을 복사해 둡니다: Project URL, anon public key

## 2. 로컬 실행

```bash
npm install
cp .env.example .env      # 복사한 URL 과 anon key 를 .env 에 입력
npm run dev
```

`http://localhost:5173` 접속 → 3번에서 만든 계정으로 로그인.

> 서비스워커는 운영 빌드에서만 등록됩니다. 개발 중 캐시 때문에 방금 고친 코드가 안 보이는 일을 막기 위해서입니다.
> 오프라인 동작을 직접 확인하려면 `npm run build && npm run preview` 로 띄우세요.

## 3. 배포

### Railway

1. 이 폴더를 GitHub 저장소에 push.
2. Railway → **New Project → Deploy from GitHub repo**.
3. **Variables** 에 환경변수 2개 추가: `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`
4. Build/Start 명령은 package.json 에 이미 정의돼 있습니다 (`build` → `start`).
5. **Settings → Networking → Generate Domain** 으로 주소 생성.

### Vercel (대안)

Import repo → Framework: Vite → 환경변수 2개 추가 → Deploy.

> `/pricing` 처럼 앱 안에서만 존재하는 주소가 있으므로, 정적 호스팅에는 **SPA 폴백**
> (알 수 없는 경로 → `index.html`)이 필요합니다. `vite preview`(Railway) 와 Vercel 은 기본으로 해 줍니다.

> anon key 는 브라우저에 노출돼도 되는 공개 키입니다. 실제 데이터 보호는 RLS 정책(본인 user_id 만 접근)이 담당합니다.
> `service_role` 키는 절대 프론트엔드에 넣지 마세요.

## 4. 폰에 설치하기

배포된 주소를 폰 브라우저로 연 뒤,

- **Android (Chrome)**: 메뉴 → "앱 설치" 또는 "홈 화면에 추가"
- **iOS (Safari)**: 공유 → "홈 화면에 추가"

설치하면 주소창 없이 전체 화면으로 뜨고, 오프라인에서도 앱 화면은 열립니다.
(다만 목록·저장은 Supabase 연결이 필요하므로 온라인일 때만 동작합니다.)

## 커스터마이징

- **색 팔레트**: `src/styles.css` 맨 위의 `:root` (라이트) 와 `:root[data-theme='dark']` (다크).
  카테고리 색 키는 `src/supabase.js` 의 `COLOR_KEYS` 와 이름이 맞아야 합니다.
- **카테고리 아이콘 후보**: `src/supabase.js` 의 `ICON_CHOICES`
- **페이지 크기**: `src/supabase.js` 의 `PAGE_SIZE`
- **앱 아이콘**: `scripts/generate-icons.mjs` 의 색·글리프를 고치고 다시 실행
- **서비스워커 캐시**: `public/sw.js` 의 `VERSION` 을 올리면 옛 캐시가 정리됩니다

## 개발 메모

- 번들(gzip): 앱 코드 약 17 kB / react 45 kB / supabase-js 57 kB / CSS 5 kB.
  가장 큰 조각은 `@supabase/supabase-js` 이고, 이 앱이 쓰지 않는 realtime 이 함께 들어 있습니다.
